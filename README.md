# MoreDuos

A Hades II mod that adds 37 new Duo Boons, one or two for nearly every pairing of Olympians, plus a
Chaos Legendary. Every duo is independent and can be switched off on its own.

Please note: installing [the companion mod, BoonEdits](https://thunderstore.io/c/hades-ii/p/SWu/BoonEdits/) is highly recommended!

## Features

- New Duos across every Olympian pairing — see the Wiki tab for the full list.
- One toggle per duo in `ReturnOfModding/config/SWu-MoreDuosMod.cfg`. Nothing is all-or-nothing.

## Install

Install through a mod manager (Thunderstore or r2modman) to pull in dependencies.
To install by hand, drop the folder into `ReturnOfModding/plugins/` and make sure these are present:
Hell2Modding, ENVY, Chalk, ReLoad, SJSON, ModUtil, GodsAPI, Droppable Gods and HexReroll.

## Configuration

Launch the game once to generate `ReturnOfModding/config/SWu-MoreDuosMod.cfg`, then configure (enable/disable) any duo boons. 

`Experimental` changes are off by default (includes limited support for Zagreus' Journey and Wrath of Olympus) -- enable at your own risk!

Be sure to relaunch the game each time you make changes to the config.
